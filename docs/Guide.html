Verify egress, then observe Codex

Configure your node, target IP, ports and selector group first. Run on the actual machine hosting your Codex process.

python3 -m codex_vpn sample --device local
python3 -m codex_vpn watch --device local --seconds 120 --pid 12345

Replace the device ID and PID. Send a real request in that Codex while watch is running. NETWORK probes and a correct socket-PID chain are separate evidence.

  • Green main dot: fresh exit probes and selected node match.
  • Green C: a PID-associated Codex connection used the target node.
  • Amber C: evidence incomplete or expired; idle is not a failure or a pass.
  • Red: mismatch, failed probe, or observed connection conflict.

No claim of all future traffic or leak prevention. A curl request does not prove model traffic. TUN is not a kill switch. This app never configures TUN, DNS, subscriptions or firewall rules.
